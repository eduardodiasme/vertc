# Vertc - Coming Soon Landing Page

A high-performance, minimalist landing page for Vertc's "Coming Soon" announcement.

## Overview

This is a static HTML/CSS/JavaScript landing page featuring:

- **Minimalist Design**: Dark theme with high-contrast typography
- **Glassmorphism Effect**: Interactive Apple-style glassmorphism on the headline
- **Responsive Layout**: Fully responsive design that adapts to all screen sizes
- **Performance Optimized**: Lightweight vanilla JavaScript with no framework dependencies

## Project Structure

```
.
├── index.html          # Main HTML file
├── styles.css         # Stylesheet with responsive design
├── script.js          # JavaScript for glassmorphism effect
├── .gitignore         # Git ignore rules
└── README.md          # This file
```

## Features

- **Headline**: "Architecture Over Chaos." with interactive glassmorphism effect
- **Responsive Design**: Mobile-first approach with breakpoints at 1024px, 768px, and 480px
- **Performance**: Pure HTML/CSS/JS with no external dependencies
- **SEO Optimized**: Includes meta tags, Open Graph tags, and semantic HTML

## Deployment

### GitHub Pages

1. Go to your repository settings on GitHub
2. Navigate to **Settings > Pages**
3. Under **Source**, select the branch (usually `master` or `main`)
4. Select the root folder (`/`)
5. Click **Save**
6. Your site will be available at `https://eduardodiasme.github.io/vertc/`

### Other Hosting Options

This is a static site that can be deployed to any static hosting service:

- **Static Hosting**: Netlify, Vercel, etc.
- **Traditional Web Server**: Apache, Nginx, etc.
- **CDN**: Cloudflare Pages, AWS S3 + CloudFront, etc.

Simply upload the files to your hosting provider's web root directory.
